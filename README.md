# Turini 금융 학습 앱 — 전체 소스

기린 캐릭터 투리니와 함께 금융을 배우는 모바일 중심 웹앱입니다. 이 폴더에는 화면 코드뿐 아니라 학습·진단 데이터, 이미지, 출제 스케줄러, 자동 검사, 빌드 및 배포 설정이 모두 들어 있습니다.

별도 유료 API나 데이터베이스가 필요하지 않습니다. 학습 기록과 포트폴리오 입력은 각 사용자의 브라우저 저장소에 따로 보관되므로 여러 사람이 같은 사이트 주소를 이용해도 서로의 기록이 섞이지 않습니다.

## 1. 내 컴퓨터에서 실행

준비물: Node.js 22.13 이상

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 열면 됩니다. `index.html`을 파일로 직접 여는 방식은 사용하지 않습니다.

## 2. 자동 검사

```bash
npm test
```

이 명령은 운영용 빌드와 함께 다음 항목을 검사합니다.

- 학습 문항 720개와 180개 기본 개념의 구조
- 기본 개념별 4개 유형 연결
- 2,500개 가상 세션의 의도하지 않은 개념 중복
- 새 개념 7개 + 복습 3개 출제
- 오답의 3~5문제 뒤 다른 유형 재출제
- 세션 마지막 오답의 다음 세션 복습 연결
- 중복 개념 통합 및 복습 카테고리 유지
- 객관식 정답 위치 섞기
- 직접입력 180문항의 자연스러운 답안 채점
- 진단 원점수 21/22점, 38/39점 경계

## 3. 다른 사람도 쓰도록 새로 배포

가장 쉬운 방법은 이 ZIP 파일 전체를 ChatGPT Work에 첨부하고 다음처럼 요청하는 것입니다.

> 이 ZIP의 투리니 앱 소스로 새 Sites 프로젝트를 만들고, 누구나 접속할 수 있게 공개 배포해줘. 기존 `.openai/hosting.json`은 원본 사이트의 연결 정보이므로 새 프로젝트 연결 정보로 교체해줘.

배포가 끝나면 공개 주소 하나를 여러 사람에게 공유하면 됩니다. 사용자별 학습 기록은 각자의 브라우저에 저장됩니다.

원본 사이트를 소유한 계정에서 기존 사이트를 이어서 수정할 때는 `.openai/hosting.json`을 그대로 유지해야 합니다. 다른 계정이 독립된 새 사이트를 만들 때는 기존 연결 정보를 재사용하면 안 됩니다.

## 4. 주요 기능

- 학습 문항 720개: 주식, 채권, 펀드/ETF, 위험 관리, 분산 투자, 수익률 계산
- 문항 유형 4개: 4지선다, OX, 빈칸선택, 빈칸직접입력
- 초급·중급·고급 난이도와 30개 레벨 경로
- 수준 진단 18문항 + 투자 성향 진단 3문항
- 정답 즉시 피드백, 해설, 공식 검증 출처 링크
- 새 개념과 간격 반복 복습을 섞는 학습 스케줄러
- 같은 세션의 우연한 개념 중복 방지 및 오답 복습 표시
- 공백·문장부호·자연스러운 한국어 어미·주요 동의어를 허용하는 주관식 채점
- XP, 연속 학습, 완료 문제, 약점 태그 저장
- 포트폴리오 자산 6종: 국내주식, 해외주식, 채권, ETF/펀드, 현금성자산, 금
- 포트폴리오 점수, 위험도, 성향 적합도, 분산도, 집중도 분석
- 목표 비중과 총금액 기준 리밸런싱 금액 계산

## 5. 중요한 파일

| 경로 | 내용 |
| --- | --- |
| `app/page.tsx` | 앱 전체 화면과 주요 기능 |
| `app/globals.css` | 모바일·PC 반응형 디자인 |
| `app/quiz-scheduler.ts` | 신규·복습·오답 재출제 규칙 |
| `app/answer-utils.ts` | 직접입력 정답 판정 |
| `app/diagnosis-utils.ts` | 진단 점수 경계 판정 |
| `public/data/quizData_720_FINAL.json` | 학습 문항 720개 |
| `public/data/diagnostic_quiz.json` | 진단 문항 21개 |
| `public/assets/` | 투리니 캐릭터 이미지 |
| `tests/` | 출제·데이터·채점·진단 자동 검사 |
| `.openai/hosting.json` | 원본 Sites 연결 정보 |

## 6. 저장 및 운영 방식

- 별도 API 키 없음
- 별도 서버 DB 없음
- 브라우저 `localStorage`에 사용자별 진행 상황 저장
- 공개용 초기 화면: 처음 접속한 사용자는 21문항 진단 테스트부터 시작
- 개인 이름·학번 없이 `학습자님` / `투리니 학습자`로 공통 표시
- 브라우저 데이터 삭제 또는 다른 기기 사용 시 기록은 자동 이동되지 않음
- 포트폴리오 분석은 금융 학습용이며 특정 종목·상품의 매수·매도를 권유하지 않음

학습 문항에는 출처명, 출처 URL, 검증 상태, 난이도, 약점 태그, 해설이 포함되어 있습니다.
