# Turini 금융 학습 앱

기린 캐릭터 **투리니**와 함께 금융 개념을 학습하는 모바일 중심 웹앱입니다.

주식, 채권, 펀드·ETF, 위험관리, 분산투자, 수익률 계산을 단계별로 학습할 수 있으며, 진단 결과를 통해 금융 이해 수준과 투자 성향을 확인할 수 있습니다.

## 주요 기능

- 금융 학습 문항 720개
- 180개 기본 개념을 4가지 유형으로 구성
  - 4지선다
  - OX
  - 빈칸 선택
  - 빈칸 직접 입력
- 금융 수준 진단 18문항과 투자 성향 진단 3문항
- 초급·중급·고급 난이도 구성
- 6개 카테고리별 독립적인 학습 기록과 레벨
- 카테고리별 12개 학습 단계와 오답 복습
- 정답 즉시 확인, 해설 및 출처 제공
- 신규 개념과 복습 문항을 조합하는 학습 스케줄러
- 아이디와 숫자 비밀번호 4자리를 이용한 계정 기능
- 아이디별 진단·학습·포트폴리오 기록 저장
- 포트폴리오 위험도·성향 적합도·분산도·집중도 분석
- 목표 비중과 리밸런싱 금액 계산

## 카테고리별 학습

학습 카테고리는 다음 6개로 구성됩니다.

1. 주식
2. 채권
3. 펀드·ETF
4. 위험관리
5. 분산투자
6. 수익률 계산

각 카테고리의 학습 기록과 레벨은 서로 독립적으로 계산됩니다. 해당 카테고리에서 완료한 고유 문항 10개마다 레벨이 1씩 상승하며, 최대 레벨은 12입니다. 새 계정은 모든 카테고리를 Lv.1부터 시작합니다.

## 실행 방법

### 준비 사항

- Node.js 22.13 이상

### 로컬 실행

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 열어 실행합니다.

### 자동 검사

```bash
npm test
```

### 운영용 빌드

```bash
npm run build
npm start
```

## 데이터 저장 방식

- 아이디는 대소문자를 구분하지 않으며 중복 생성을 방지합니다.
- 숫자 비밀번호 4자리는 해시된 값으로 저장하며 원문은 저장하지 않습니다.
- 진단 결과, 카테고리별 학습 진행도와 포트폴리오 기록은 계정별로 분리하여 저장합니다.
- 같은 계정으로 로그인하면 다른 기기에서도 기존 기록을 이어서 사용할 수 있습니다.
- 새 계정은 학습 기록이 없는 Lv.1 상태로 시작하며, 진단은 최초 1회 진행합니다.
- 계정 초기화 시 비밀번호 확인 후 해당 아이디와 모든 기록을 삭제합니다.

| 경로 | 내용 |
| --- | --- |
| `app/page.tsx` | 앱 화면과 주요 기능 |
| `app/globals.css` | 모바일·PC 반응형 디자인 |
| `app/quiz-scheduler.ts` | 신규·복습·오답 재출제 규칙 |

| `public/data/quizData_720_FINAL.json` | 학습 문항 720개 |
| `public/data/diagnostic_quiz.json` | 진단 문항 21개 |
| `public/assets/` | 투리니 캐릭터 이미지 |
| `tests/` | 데이터·출제·채점·진단 자동 검사 |

## 안내

포트폴리오 분석 결과는 금융 학습을 위한 참고 정보이며, 특정 종목이나 금융상품의 매수·매도를 권유하지 않습니다.

각 학습 문항에는 난이도, 약점 태그, 해설, 출처명, 출처 URL 및 검증 상태가 포함되어 있습니다.
