# Turini 금융 학습 앱

https://turini-web-fx5q.onrender.com

카테고리 학습 레벨은 주식·채권·펀드/ETF·위험관리·분산투자·수익률 계산별로 각각 계산됩니다. 각 카테고리에서 완료한 고유 문항 10개마다 레벨이 1씩 오르며 최대 Lv.12입니다.

기린 캐릭터 **투리니**와 함께 금융 개념을 학습하는 모바일 중심 웹앱입니다.

주식, 채권, 펀드·ETF, 위험 관리, 분산 투자, 수익률 계산을 단계별로 학습할 수 있으며, 진단 결과에 따라 학습 수준과 투자 성향을 확인할 수 있습니다.

## 주요 기능

- 금융 학습 문항 864개
- 216개 기본 개념을 4가지 유형으로 구성
  - 4지선다
  - OX
  - 빈칸 선택
  - 빈칸 직접 입력
- 초급·중급·고급 난이도와 카테고리별 12개 학습 레벨
- 금융 수준 진단 18문항과 투자 성향 진단 3문항
- 정답 즉시 확인 및 정중한 문체의 해설 제공(출처 정보는 데이터 검증용으로 보관)
- 신규 개념과 복습 문항을 조합하는 학습 스케줄러
- 오답 문항 재출제 및 간격 반복 학습
- 객관식 보기 순서 무작위 배치
- 문장부호, 자연스러운 어미, 주요 동의어를 허용하는 직접입력 채점
- XP, 연속 학습, 완료 문제, 상위 약점 태그 20종 저장·맞춤 추천
- 중복 확인이 있는 아이디와 숫자 비밀번호 4자리 계정
- 최초 로그인 후 진단 1회, 이후 아이디별 학습 기록 유지
- 로그아웃 및 비밀번호 확인 후 계정·전체 기록 초기화
- 포트폴리오 변동성 위험등급·성향 적합·기간 적합의 독립 판정
- 5% 단위의 근거리 학습용 배분과 비중 조정 방향 안내
- GPT가 규칙 계산 결과를 설명하는 AI 코치
- 현재 자산·월 적립금·기간·가정수익률을 이용한 미래 자산 시뮬레이션
- 목표자산 예상 달성 시점과 연도별 원금·예상자산 그래프
- 월급·소비·저축·투자를 구분하는 월간 돈 흐름 기록
- 이번 달 저축·투자 금액을 미래 자산 계산에 바로 연결

## 포트폴리오 v11 규칙

규칙 버전은 `4.0.0-portfolio-v11-document-snapshot`입니다. 종합점수·별점·Excellent/Good 등급을 만들지 않고 다음 세 축을 독립적으로 보여 줍니다.

- 서비스 변동성 위험등급: 공분산으로 계산한 연환산 변동성을 1~6등급으로 구분
- 성향 적합: 안정형·중립형·공격형 기준 범위와의 거리
- 기간 적합: `1년 미만`, `1~3년`, `3~10년`, `10년 이상` 기준 범위와의 거리

| 자산군 | 문서 기준 연환산 변동성 | 입력 범위 |
| --- | ---: | --- |
| 국내주식 | 33.69% | 국내 거래소의 개별기업 주식 |
| 해외주식 | 22.41% | 해외 거래소의 개별기업 주식 |
| 채권 | 1.69% | 직접채권, 일반 채권 ETF, 채권형 펀드 |
| 주식형 ETF·펀드 | 15.03% | 일반 주식형 ETF·펀드, 레버리지·인버스 제외 |
| 현금성자산 | 0.22% | 현금, 예금, CMA·MMF 등 |
| 금 | 19.40% | 실물 금, 금 통장, 금 현물·선물 가격 추종 상품 |

ETF·펀드는 이름이 아니라 기초자산으로 분류합니다. 화면은 0~100%, 엔진은 0.0~1.0으로 저장하며 합계가 정확히 1.0이어야 합니다. 변동성·상관계수·판정에는 반올림 전 값을 사용하고 표시만 반올림합니다.

강점은 규칙엔진이 성향 범위 충족, 유효한 분산효과, 기간 범위 충족 순서로 최대 3개 생성합니다. LLM은 이를 다시 판단하거나 숫자를 바꿀 수 없습니다. 조정안은 성향·기간 범위의 교집합에서 현재 보유 자산을 우선해 5% 격자로 찾고, 필요할 때만 현금·채권·주식형 ETF·펀드 중 한 종류를 추가합니다. 상태가 `hold`, `horizon_below_reference`, `constraint_conflict`, `no_feasible_target`이면 실행 항목을 만들지 않습니다.

> **검증 한계:** 현재 값은 2026-09-21 최종 문서에 적힌 변동성·상관계수 스냅샷을 구현한 것입니다. 원시 시장 시계열과 운영용 공분산 상수는 제공되지 않아 완전한 재현 검증은 아직 할 수 없습니다. 화면의 등급은 공식 금융상품 위험등급이 아닌 서비스용 교육 지표입니다.

이전 버전의 0~100 비중과 `fund` 필드는 자동 이전하지만, 과거 규칙으로 계산한 결과는 버전 불일치로 폐기하고 다시 분석합니다.

## 실행 방법

### 준비 사항

- Node.js 22.13 이상

### 실행

`.env.local` 파일에 `DATABASE_URL`과 `OPENAI_API_KEY`를 설정합니다. API 키는 브라우저 코드나 GitHub에 직접 넣지 않습니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열어 실행합니다.

## 자동 검사

```bash
npm test
```

자동 검사에서는 다음 항목을 확인합니다.

- 학습 문항 864개와 기본 개념 216개의 데이터 구조
- 기본 개념별 4개 문항 유형 연결
- 세션 내 의도하지 않은 개념 중복 여부
- 신규 문항과 복습 문항의 출제 비율
- 오답 문항의 다른 유형 재출제
- 다음 세션으로 이어지는 오답 복습
- 중복 개념 통합 및 카테고리 유지
- 객관식 정답 위치 무작위 배치
- 직접입력 문항 216개의 답안 판정
- 진단 점수의 초급·중급·고급 경계
- 포트폴리오 6개 자산군, 공분산 변동성, 서비스 위험등급과 성향·기간 경계
- 미래 자산 복리 계산과 월간 돈 흐름 합계
- 기존 0~100 비중과 `fund` 저장값의 0.0~1.0·`equityFund` 이전
- 무작위 포트폴리오 1,500개의 세 축 판정·추천상태·추천합계·강점 불변조건
- 운영용 빌드 가능 여부

## 배포

GitHub 저장소에 전체 소스를 업로드한 뒤 Node.js를 지원하는 배포 서비스에 연결하면 공개할 수 있습니다.

일반적인 배포 명령은 다음과 같습니다.

```bash
npm ci
npm run build
npm start
```

배포 환경에 따라 빌드 명령과 실행 명령을 각각 설정합니다.

## 데이터 저장 방식

- 무료 PostgreSQL 데이터베이스 연결이 필요합니다. Render 무료 DB는 30일 뒤 만료되므로 Neon 무료 DB 사용을 권장합니다.
- Render 환경변수 `DATABASE_URL`에 Neon의 pooled connection string을 입력합니다.
- 아이디는 대소문자를 구분하지 않고 중복을 막습니다.
- 숫자 비밀번호 4자리는 scrypt로 해시한 값만 저장하며 원문은 저장하지 않습니다.
- 진단 결과, 학습 진행도와 포트폴리오는 로그인한 아이디에 연결되어 다른 기기에서도 이어집니다.
- 새 아이디는 빈 레벨 1 상태로 시작하고 21문항 진단은 처음 한 번만 진행합니다.
- 마이 화면의 계정 초기화에서 비밀번호를 확인한 뒤 아이디와 모든 기록을 함께 삭제할 수 있습니다.

## 안내

포트폴리오 분석 결과는 금융 학습을 위한 참고 정보이며, 특정 종목이나 금융상품의 매수·매도를 권유하지 않습니다.

배포 시 Render의 Environment에 `OPENAI_API_KEY`를 등록해야 GPT 코칭이 작동합니다. 키가 없거나 호출에 실패하면 기존 규칙 분석 결과가 대신 표시됩니다.

각 학습 문항에는 난이도, 약점 태그, 해설, 출처명, 출처 URL 및 검증 상태가 포함되어 있습니다.
