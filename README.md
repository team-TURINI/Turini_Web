# Turini 금융 학습 앱

카테고리 학습 레벨은 주식·채권·펀드/ETF·위험관리·분산투자·수익률 계산별로 각각 계산됩니다. 각 카테고리에서 완료한 고유 문항 10개마다 레벨이 1씩 오르며 최대 Lv.12입니다.

기린 캐릭터 **투리니**와 함께 금융 개념을 학습하는 모바일 중심 웹앱입니다.

주식, 채권, 펀드·ETF, 위험 관리, 분산 투자, 수익률 계산을 단계별로 학습할 수 있으며, 진단 결과에 따라 학습 수준과 투자 성향을 확인할 수 있습니다.

## 주요 기능

- 금융 학습 문항 720개
- 180개 기본 개념을 4가지 유형으로 구성
  - 4지선다
  - OX
  - 빈칸 선택
  - 빈칸 직접 입력
- 초급·중급·고급 난이도와 카테고리별 12개 학습 레벨
- 금융 수준 진단 18문항과 투자 성향 진단 3문항
- 정답 즉시 확인, 해설 및 출처 링크 제공
- 신규 개념과 복습 문항을 조합하는 학습 스케줄러
- 오답 문항 재출제 및 간격 반복 학습
- 객관식 보기 순서 무작위 배치
- 문장부호, 자연스러운 어미, 주요 동의어를 허용하는 직접입력 채점
- XP, 연속 학습, 완료 문제, 약점 태그 저장
- 중복 확인이 있는 아이디와 숫자 비밀번호 4자리 계정
- 최초 로그인 후 진단 1회, 이후 아이디별 학습 기록 유지
- 로그아웃 및 비밀번호 확인 후 계정·전체 기록 초기화
- 포트폴리오 위험도·성향 적합도·분산도·집중도 분석
- 목표 비중 및 리밸런싱 금액 계산
- GPT가 규칙 계산 결과를 설명하는 AI 코치

## 포트폴리오 자산 분류와 위험가중치

포트폴리오는 다음 6개 자산군을 사용합니다. 위험가중치는 공식 수익률 예측값이 아니라 자산군 사이의 상대적 위험을 계산하기 위한 내부 지수입니다.

| 자산군 | 위험가중치 | 입력 범위 |
| --- | ---: | --- |
| 국내주식 | 60 | 국내 거래소의 개별기업 주식 |
| 해외주식 | 65 | 해외 거래소의 개별기업 주식 |
| 채권 | 25 | 직접채권, 일반 채권 ETF, 채권형 펀드 |
| 주식형 ETF·펀드 | 50 | 일반 주식형 ETF·펀드와 금광기업 주식형, 레버리지·인버스 제외 |
| 현금성자산 | 5 | 현금, 예금, CMA·MMF 등 |
| 금 | 40 | 실물 금, 금 통장, 금 현물·선물 가격 추종 상품 |

ETF·펀드는 상품의 이름이 아니라 기초자산에 따라 분류합니다. 채권 ETF·채권형 펀드는 `채권`, 주식형 ETF·펀드는 `주식형 ETF·펀드`에 입력하고, 혼합형 펀드는 공시된 주식·채권 비중에 따라 나누어 입력합니다. 이름에 금이 들어가더라도 금광기업 주식에 투자하는 상품은 `금`이 아니라 `주식형 ETF·펀드`입니다. 구성비를 확인할 수 없는 혼합형 상품은 임의로 분류하지 않습니다. 각 입력 항목의 `ⓘ` 버튼에서는 포함 범위와 제외 상품을 확인할 수 있습니다. 내부 위험가중치는 사용자 화면에 표시하지 않고 규칙 문서와 코드에서만 관리합니다.

주식형 ETF·펀드 50은 주식시장 전체의 가격변동 위험을 반영하되, 여러 종목에 분산투자하여 개별기업 위험을 줄일 수 있는 점을 반영한 내부 분석가중치입니다. 따라서 채권 25와 금 40보다 높고 국내·해외 개별주식 60·65보다 낮게 설정했습니다. 이 값은 금융기관의 공식 공통점수가 아니라 서비스의 5~65 상대위험 척도에서 사용하는 내부 기준입니다. 참고 기준은 [금융투자협회 표준투자권유준칙](https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1193&seq=149), [미래에셋증권 금융투자상품 위험도 분류표](https://securities.miraeasset.com/hku/hku4028/p01.do), [KODEX 200 공식 상품자료](https://m.samsungfund.com/sheet/20250402/2ETF01_20250331.pdf), [Vanguard 주식형 펀드 설명](https://investor.vanguard.com/investor-resources-education/understanding-investment-types/what-are-equity-stock-funds)입니다.

사용자 화면에서는 비중을 0~100%로 입력·표시하고, 내부 `allocation`은 0.0~1.0으로 저장·계산합니다. 내부 합계는 1.0이어야 하며 99~101%를 허용하지 않고 부동소수점 계산의 미세한 오차만 허용합니다.

규칙 버전은 `3.0.4-portfolio-v9.1`입니다. 위험점수는 화면에서 소수 첫째 자리로 표시하지만 유형·성향일치·기간적합·강점·경고 판정에는 반올림 전 원값을 사용합니다. 성향 중심은 30.5·41.0·52.8, 유형 경계는 35.75·46.9, 투자기간 중심은 20·40·55·70입니다. 이전 버전의 0~100 비중과 `fund` 필드는 불러올 때 0.0~1.0 비중과 `equityFund`로 자동 이전하지만, 예전 규칙으로 계산된 분석 결과는 다시 사용하지 않고 사용자가 새 규칙으로 재분석하도록 처리합니다.

종합점수는 성향일치도 45%, 자산군 분산도 25%, 기간적합도 15%에서 집중 페널티를 빼는 내부 85점 척도입니다. Excellent는 82점부터이며 화면에 85점 만점임을 표시합니다. 강점은 성향일치도 80점 이상, 분산도 85점 이상, 기간적합도 80점 이상에서만 생성하고 기준을 충족한 항목이 없으면 빈 상태를 허용합니다. 분산도와 집중도는 자산군 사이의 분산만 평가하며 같은 자산군 안의 종목·업종·국가 집중위험은 평가하지 않습니다.

## 실행 방법

### 준비 사항

- Node.js 22.13 이상

### 실행

`.env.local` 파일에 `DATABASE_URL`과 `OPENAI_API_KEY`를 설정합니다. API 키는 브라우저 코드나 GitHub에 직접 넣지 않습니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열어 실행합니다.

## 자동 검사

```bash
npm test
```

자동 검사에서는 다음 항목을 확인합니다.

- 학습 문항 720개와 기본 개념 180개의 데이터 구조
- 기본 개념별 4개 문항 유형 연결
- 세션 내 의도하지 않은 개념 중복 여부
- 신규 문항과 복습 문항의 출제 비율
- 오답 문항의 다른 유형 재출제
- 다음 세션으로 이어지는 오답 복습
- 중복 개념 통합 및 카테고리 유지
- 객관식 정답 위치 무작위 배치
- 직접입력 문항 180개의 답안 판정
- 진단 점수의 초급·중급·고급 경계
- 포트폴리오 6개 자산군, 위험가중치, 목표 중심과 유형 경계의 정합성
- 기존 0~100 비중과 `fund` 저장값의 0.0~1.0·`equityFund` 이전
- 무작위 포트폴리오 20,000개의 위험점수·점수·추천합계·경고·강점 불변조건
- 운영용 빌드 가능 여부

## 배포

GitHub 저장소에 전체 소스를 업로드한 뒤 Node.js를 지원하는 배포 서비스에 연결하면 공개할 수 있습니다.

일반적인 배포 명령은 다음과 같습니다.

```bash
npm ci
npm run build
npm start
```

배포 환경에 따라 빌드 명령과 실행 명령을 각각 설정합니다.

## 데이터 저장 방식

- 무료 PostgreSQL 데이터베이스 연결이 필요합니다. Render 무료 DB는 30일 뒤 만료되므로 Neon 무료 DB 사용을 권장합니다.
- Render 환경변수 `DATABASE_URL`에 Neon의 pooled connection string을 입력합니다.
- 아이디는 대소문자를 구분하지 않고 중복을 막습니다.
- 숫자 비밀번호 4자리는 scrypt로 해시한 값만 저장하며 원문은 저장하지 않습니다.
- 진단 결과, 학습 진행도와 포트폴리오는 로그인한 아이디에 연결되어 다른 기기에서도 이어집니다.
- 새 아이디는 빈 레벨 1 상태로 시작하고 21문항 진단은 처음 한 번만 진행합니다.
- 마이 화면의 계정 초기화에서 비밀번호를 확인한 뒤 아이디와 모든 기록을 함께 삭제할 수 있습니다.

## 안내

포트폴리오 분석 결과는 금융 학습을 위한 참고 정보이며, 특정 종목이나 금융상품의 매수·매도를 권유하지 않습니다.

배포 시 Render의 Environment에 `OPENAI_API_KEY`를 등록해야 GPT 코칭이 작동합니다. 키가 없거나 호출에 실패하면 기존 규칙 분석 결과가 대신 표시됩니다.

각 학습 문항에는 난이도, 약점 태그, 해설, 출처명, 출처 URL 및 검증 상태가 포함되어 있습니다.
