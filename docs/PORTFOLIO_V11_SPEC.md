# Turini 포트폴리오 v11 활성 규칙

기준 문서: 사용자 제공 `v11 · 최최종수정안 · 2026-09-21`  
구현 버전: `4.0.0-portfolio-v11-document-snapshot`

이 문서는 앱에 실제 반영된 규칙의 짧은 기준표입니다. 앞선 두 수정안과 충돌하면 2026-09-21 최종 수정안을 우선합니다.

## 출력

종합점수는 사용하지 않습니다. 연환산 변동성 기반 서비스 위험등급, 성향 적합, 기간 적합을 독립 판정합니다. 화면의 등급은 공식 금융상품 위험등급이 아닙니다.

화면에서 `%` 단위를 붙이는 값은 연환산 변동성·기준 범위·비중처럼 실제 비율인 값뿐입니다. 성향 적합과 기간 적합의 내부 `0~1` 값은 확률이 아니므로 사용자 화면에는 백분율로 표시하지 않고 `적합`, `다소 안정적`, `기간 대비 위험이 높음` 같은 판정 문구로 표시합니다.

## 자산과 연환산 변동성

행렬 순서는 국내주식, 해외주식, 주식형 ETF·펀드, 채권, 현금성자산, 금입니다.

| 자산 | 변동성 |
| --- | ---: |
| 국내주식 | 33.69% |
| 해외주식 | 22.41% |
| 주식형 ETF·펀드 | 15.03% |
| 채권 | 1.69% |
| 현금성자산 | 0.22% |
| 금 | 19.40% |

```text
1.00  0.15  0.69  0.16  0.04  0.17
0.15  1.00  0.49 -0.03 -0.01 -0.01
0.69  0.49  1.00  0.09  0.02  0.12
0.16 -0.03  0.09  1.00  0.53  0.22
0.04 -0.01  0.02  0.53  1.00  0.15
0.17 -0.01  0.12  0.22  0.15  1.00
```

`Sigma_ij = corr_ij * sigma_i * sigma_j`, `sigma_p = sqrt(w' Sigma w)`를 사용합니다. 위험수준은 `sigma_p / 33.69`, 6개월 하방 참고값은 `expm1(-1.645 * sigma_p * sqrt(26/52))`입니다.

## 기준 배분

| 성향 | 국내 | 해외 | 주식형 | 채권 | 현금 | 금 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 안정형 | 5% | 10% | 5% | 45% | 30% | 5% |
| 중립형 | 12.5% | 25% | 12.5% | 35% | 10% | 5% |
| 공격형 | 17.5% | 35% | 17.5% | 15% | 5% | 10% |

성향 범위는 세 중심 사이의 중간점, 기간 범위는 단기 중심과 세 성향 중심 사이의 중간점으로 닫힌 구간을 만듭니다. 기간 선택지는 `1년 미만`, `1~3년`, `3~10년`, `10년 이상`입니다.

## 강점·주의·추천

- 강점은 성향 범위 충족, 유효한 분산효과, 기간 범위 충족 순서로 0~3개입니다.
- 분산효과는 보유 자산 2종 이상이고 `1 - sigma_p / sum(w_i sigma_i) > 0`일 때만 강점입니다.
- 강점 문장은 판정만 적지 않고 현재 연환산 변동성, 해당 기준 범위, 보유 자산 수, 계산된 분산효과 감소율 중 그 판정에 직접 사용한 숫자를 함께 적습니다.
- 주의 신호는 성장자산, 방어자산, 현금의 상·하한 여섯 개뿐입니다.
- 현재 변동성이 성향·기간 범위에 모두 들면 `hold`입니다.
- 성향에는 맞지만 기간 하한보다 낮으면 위험을 억지로 올리지 않고 `horizon_below_reference`입니다.
- 두 범위가 겹치지 않으면 `constraint_conflict`입니다.
- 그 밖에는 5% 격자에서 현재 보유 자산을 우선하고, 필요할 때 현금→채권→주식형 ETF·펀드 중 한 종류만 추가해 가까운 배분을 찾습니다.
- 5%p 이상 차이만 실행 항목이며 작은 차이는 잔차로 분리합니다.
- LLM은 계산·강점·주의·조정안을 바꾸지 않고 요약만 작성합니다.

강점 문장 형식이 바뀌면 기존 LLM 사람 검수 CSV의 기대 출력도 달라지므로 같은 입력으로 다시 호출해 새 CSV를 만들어야 합니다. 이전 CSV를 새 규칙 결과의 합격 근거로 재사용하지 않습니다.

## 근거 수준과 남은 공백

| 항목 | 현재 근거 | 판정 |
| --- | --- | --- |
| 공분산 포트폴리오 변동성 | `sigma_p = sqrt(w' Sigma w)` 계산식과 코드·회귀 테스트 | 계산 근거 있음 |
| 성향·기간 적합 | 문서의 기준 배분에서 계산한 중심값과 인접 중심의 중간점 | 서비스 내부 판정 기준 |
| 성장·방어·현금 주의 신호 | 세 성향별 기준 배분의 인접 중간점 | 서비스 내부 판정 기준 |
| 강점 | 성향 범위, 분산효과 식, 기간 범위의 독립 조건과 실제 계산값 | 재현 가능 |
| 자산별 변동성·상관계수 숫자 | 2026-09-21 v11 문서 스냅샷 | 원시 자료·산출 코드 없음 |
| 서비스 1~6 위험등급 경계 | v11 문서에 고정 | 공식 규제 등급이 아닌 내부 기준 |
| 6개월 하방 참고값 | 정규분포 가정식 | 실제 손실 예측이 아닌 참고값 |

따라서 현재 엔진은 **문서에 주어진 숫자를 동일하게 재현하는 서비스 규칙**으로는 검증됐지만, 자산별 변동성·상관계수를 데이터 수집 단계부터 다시 계산했다는 근거는 아직 없습니다. 원시 시계열, 관측 기간, 수익률 주기, 통화·환헤지 처리, 결측치 처리 기준을 확보하기 전에는 `document_snapshot_unverified` 상태를 유지합니다.

## 외부 기준과의 관계

- ESMA/CESR의 UCITS SRRI 방법론은 과거 수익률의 변동성을 바탕으로 1~7 등급을 산출합니다. 이 앱의 1~6 서비스 등급은 척도와 경계가 다르므로 공식 SRRI로 표현하지 않습니다: <https://www.esma.europa.eu/document/guidelines-methodology-calculation-synthetic-risk-and-reward-indicator-in-key-investor>
- 미국 SEC Investor.gov는 분산투자를 여러 투자에 자금을 나누어 위험을 줄이는 방법으로 설명하지만 손실 방지를 보장하지는 않는다고 안내합니다. 앱의 분산효과 문구도 `위험 감소 계산값`으로만 표시하고 수익·손실 방지 보장으로 표현하지 않습니다: <https://www.investor.gov/introduction-investing/getting-started/asset-allocation>
