# 10문제 챕터 출제·진도·해설 수정

## 적용 범위

주식, 채권, 펀드/ETF, 위험 관리, 분산 투자, 수익률 계산의 모든 12개 레슨에 적용합니다. 레슨 1–4는 초급, 5–8은 중급, 9–12는 고급입니다.

## 출제

- 카테고리와 난이도로 후보를 먼저 제한합니다. 해당 범위를 넘어가는 오답 복습 대체 문항도 차단합니다.
- 기존 main의 레슨 후보 수정(PR #21)을 유지합니다. 추가로 미풀이·최근 학습 기록이 있는 계정에서도 세션 전체의 유형 할당량을 맞춥니다.
- 10문제는 4지선다·OX·빈칸선택·빈칸직접입력을 각각 2–3개(2·2·3·3) 포함합니다. 추가 한 문제씩 받는 두 유형은 시드에 따라 달라집니다.
- 최초 출제는 서로 다른 개념 10개입니다. 오답은 기존 동작대로 다른 유형으로 복습하며, 세션 길이는 10문제입니다.
- 예약 복습 위치를 유지하고 나머지는 같은 유형이 연속되지 않게 배치합니다. 고정 복습 위치끼리 충돌하는 예외에는 기존 순서를 유지합니다.

## 해설

전체 864개 해설을 보기 번호 참조 여부로 검사했습니다. 번호에 의존하던 해설은 아래 두 개념의 네 유형씩, 총 8개였습니다. 보기 순서를 바꾸거나 OX·직접입력으로 출제할 때도 의미가 유지되도록 개념 중심 설명으로 바꿨습니다.

| 카테고리 | 난이도 | 개념 | 문항 ID |
| --- | --- | --- | --- |
| 위험 관리 | 초급 | 환금성 | RSK_B_002_MCQ, RSK_B_002_OX, RSK_B_002_BLANK_CHOICE, RSK_B_002_BLANK_INPUT |
| 분산 투자 | 초급 | Diversification | DIV_B_002_MCQ, DIV_B_002_OX, DIV_B_002_BLANK_CHOICE, DIV_B_002_BLANK_INPUT |

이는 보기 번호 참조 오류의 전수 검사 결과입니다. 모든 금융 내용에 대한 신규 사실 검증을 의미하지 않습니다. 문항·정답·태그·출처는 변경하지 않았습니다.

## 진도

- 난이도 카드의 완료 수는 해당 카테고리·난이도의 실제 완료 문항만 집계합니다. 전체 카테고리 완료 수를 초급에 몰아넣던 계산을 제거했습니다.
- 계정 복원 시 학습 데이터에 없는 진단 ID 및 중복 ID를 학습 완료 수에서 제외합니다.
- 진단은 학습 완료·시도 수에 새로 추가되지 않습니다. 기존 PR #21의 카테고리별 완료 레슨 기록과 다음 레슨 잠금 해제를 유지합니다.
- 사용자의 계정 DB 기록은 직접 조회하지 않았으므로 기존 화면의 ‘17개’가 어느 기록에서 발생했는지는 확정하지 않습니다. 기록 전체를 초기화하지 않습니다.

## 검증

- 전체 테스트 154개 통과.
- 6개 카테고리 × 12개 레슨 × 5개 시드에서 유형 균형, 난이도 분리, 최초 출제 순서 확인.
- 6개 카테고리 × 3개 난이도 × 16회 반복 학습(총 288세션)에서 완료 이력·최근 이력·오답 복습을 적용한 뒤에도 10문제 및 유형별 2–3개 유지 확인.
- 진단 ID 제거·중복 제거 및 초급 10개/중급 7개 이력의 난이도별 분리 집계 확인.
- TypeScript 검사 통과, lint 오류 0개(기존 img 경고 2개).
- Next.js production build (`npm run build -- --webpack`) 성공.
