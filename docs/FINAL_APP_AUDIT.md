# Turini 최종 앱 반영 점검

기준일: 2026-09-22

## 학습·진단

| 점검 항목 | 최종 반영 상태 |
| --- | --- |
| 학습 데이터 | `quizData_864_FINAL.json` 864문항을 앱이 직접 불러옵니다. |
| 추가 144문항 | 36개 신규 개념, 카테고리별 24문항, 난이도별 48문항, 유형별 36문항이 포함됩니다. 완료 이력이 있는 계정에는 아직 풀지 않은 신규 문항을 우선합니다. |
| 문제 유형 균형 | 10문제 세션마다 4지선다·OX·빈칸선택·빈칸직접입력이 각각 2~3회 나오도록 고정합니다. 오답 재출제가 들어와도 같은 균형을 유지합니다. |
| 해설 말투 | 학습 864문항과 진단 21문항의 원본 데이터를 정중한 `~습니다/~입니다`체로 통일하고, 화면에서도 변환 함수를 한 번 더 적용합니다. |
| 취약 태그 | 사용자 화면에는 20개 `parent_tag`만 저장·표시합니다. 홈, 결과, 마이 화면에서 확인하고 눌러 맞춤 학습을 시작할 수 있습니다. |
| 취약 태그 추천 | 오늘의 맞춤 학습과 태그 버튼 학습이 해당 `parent_tag` 문항에 가중치를 줍니다. |
| 진단 종료 | 진단 결과 화면에는 `홈으로`만 표시하고 `10문제 더 풀기`는 표시하지 않습니다. |
| 진단 집계 제외 | 진단 18개 지식 문항은 학습 시도 수, 정답 수, 완료 문항 수, 학습 세션, 연속 학습에 포함하지 않습니다. |
| 난이도 잠금 | 초급 4레슨 완료 전 중급, 중급 4레슨 완료 전 고급 시작 버튼을 비활성화합니다. |
| 상단 카테고리·레벨 | 학습 경로와 난이도 화면에서만 현재 카테고리와 해당 카테고리 레벨을 표시합니다. 다른 화면은 화면명만 표시합니다. |

## 포트폴리오

| 점검 항목 | 최종 반영 상태 |
| --- | --- |
| 종합점수 | 사용하지 않습니다. |
| 위험 출력 | 서비스 위험등급 1~6과 연환산 변동성 `%`를 구분해 표시합니다. |
| 성향·기간 출력 | 내부 0~1 값을 `%`로 표시하지 않고 판정 문구와 기준 범위를 표시합니다. |
| 강점 | 성향 적합, 유효한 분산효과, 기간 적합의 최대 3개 독립 축만 사용합니다. 각 문장에 실제 계산값과 기준 범위를 포함합니다. |
| 조정안 | 성향·기간 범위가 겹칠 때만 5% 격자에서 계산합니다. 5%p 이상 차이만 실행 항목으로 표시합니다. |
| LLM 역할 | 서버가 원시 입력으로 규칙 결과를 다시 계산하고, LLM은 결과를 설명만 합니다. 새 숫자·종목 추천·수익 보장은 차단합니다. |
| 검수 CSV | 강점 문장이 바뀌었으므로 이전 CSV를 재사용하지 않고 새 출력으로 다시 작성해야 합니다. |

## 근거 한계

자산별 변동성·상관계수와 위험등급 경계는 v11 문서 스냅샷과 코드 사이에서 일치합니다. 다만 원시 시계열과 산출 코드가 저장소에 없으므로 데이터 수집 단계부터의 재현 검증은 완료되지 않았습니다. 이 상태를 앱과 규칙 결과에 `document_snapshot_unverified`로 유지합니다.

## 별도 확인이 필요한 자료

`720문항 업데이트에 관한 문제` 페이지 원문은 이 저장소에 포함되어 있지 않습니다. 따라서 앱의 864문항 반영 상태는 검증했지만, 해당 페이지가 교수님 피드백 문구를 충분히 설명하는지는 페이지 원문을 별도로 대조해야 합니다.
