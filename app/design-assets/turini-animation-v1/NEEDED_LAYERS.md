# 2단계에 필요한 레이어 이미지 목록

현재 자산(V2 아틀라스)은 **한 장짜리 그림 24장을 이어 붙인 프레임 방식**입니다.
프레임을 갈아 끼워서 만드는 동작은 전부 구현했지만, 아래 동작은 신체 부위를
따로 움직여야 해서 프레임만으로는 만들 수 없습니다.

| 만들지 못한 동작 | 이유 |
| --- | --- |
| 임의의 시점에 눈만 깜박이기 | 눈이 몸통과 한 장으로 붙어 있어, 깜박임이 그려진 프레임으로만 가능 |
| 말하는 입 모양 (아, 이, 우) | 같은 이유. 입만 따로 움직일 수 없음 |
| 고개를 좌우로 돌리기 | 목 뒤쪽 픽셀이 없어 머리를 돌리면 빈 구멍이 생김 |
| 팔을 임의 각도로 흔들기 | 어깨 관절이 없어 회전하면 몸통에 사각형 자국이 남음 |
| 걷기 (다리 교대) | 두 다리가 몸통과 한 덩어리 |
| 시선 추적 (마우스·문항을 따라 봄) | 동공이 흰자와 분리되어 있지 않음 |

## 요청 규격 (공통)

- 형식: PNG-24 + 알파
- 캔버스: **1200 × 1200 px, 모든 레이어 동일 크기·동일 원점**
  (레이어끼리 좌표가 1px이라도 어긋나면 리깅이 성립하지 않습니다)
- 캔버스 안에 여백을 넣지 말 것. 안전 여백은 앱에서 CSS로 줍니다.
- 관절 부위는 **10~15px 겹치게** 그려 주세요. 회전할 때 틈이 벌어지지 않습니다.
- 파일명: `turini-<부위>.png` (아래 표의 이름 그대로)

## Rive / Lottie 는 지금 단계에서 필요하지 않습니다

- 위 레이어만 받으면 **추가 라이브러리 없이 CSS `transform` 만으로** 눈 깜박임,
  입 모양, 고개 끄덕임, 팔 흔들기, 걷기까지 전부 구현됩니다. 번들 용량 증가 0.
- **Rive** 는 시선 추적처럼 사용자의 움직임에 실시간으로 반응하는 단계에서 검토하면 됩니다.
  (런타임 약 200KB, 벡터라 어떤 해상도에서도 잘리지 않음)
- **Lottie** 는 캐릭터 리깅에는 맞지 않고, 컨페티·코인 획득 같은 **일회성 이펙트**에만
  따로 쓰는 편이 좋습니다. 캐릭터와 무관하므로 나중에 독립적으로 추가할 수 있습니다.
