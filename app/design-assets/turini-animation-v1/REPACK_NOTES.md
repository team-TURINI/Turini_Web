# V1 아틀라스를 V2로 다시 포장한 이유

이 폴더에는 받은 원본 자산(`turini-animation-atlas-v1.*`)과, 그것을 앱에서 쓰는
`public/assets/turini-atlas-v2.png` 로 다시 포장한 스크립트가 들어 있습니다.
**그림은 다시 그리거나 늘이거나 자르지 않았습니다.** 픽셀을 그대로 옮겨 담기만 했습니다.

## 원본 V1에서 발견한 문제 세 가지

**1. 칸 간격이 실제로는 224px인데 JSON은 256px로 적혀 있었습니다.**
그래서 `turini-animation-atlas-v1.css` 대로 재생하면 캐릭터가 프레임마다 왼쪽으로
약 32px씩 밀려가다가 마지막에 제자리로 튀어 돌아옵니다. 4프레임 동안 약 97px를
미끄러지는 셈이라, 애니메이션이 아니라 흔들림으로 보입니다.

측정값 (idle 줄, 캐릭터 중심 x좌표): 176.5 → 399.5 → 623.5 → 847.5 (간격 223, 224, 224)

**2. 256px 칸 기준으로 자르면 뿔과 발이 잘립니다.**
`wrong`·`reading`·`celebrate` 줄은 뿔 끝이 칸 위쪽 경계를 넘어가고,
`correct`·`celebrate` 줄은 발이 아래쪽 경계에 닿습니다.

**3. 옆 칸 그림이 침범합니다.**
`thinking` 3번 프레임의 전구 빛살이 2번 프레임 칸 안까지 들어와서,
2번 프레임을 보여 주면 오른쪽에 정체불명의 노란 조각이 같이 보입니다.

## V2에서 한 일

- 연결 요소(connected component) 단위로 24개 프레임을 분리해 서로 침범하지 않게 했습니다.
- 가로: 실제 간격인 224px 기준으로 중심을 다시 맞춰 프레임 간 미끄러짐을 없앴습니다.
- 세로: 줄마다 가장 낮은 픽셀을 지면선으로 잡고 모든 프레임을 같은 지면에 맞췄습니다.
  **점프 높이는 그대로 보존됩니다** (예: celebrate 3번 프레임은 지면에서 29px 떠 있음).
- 칸 크기를 288px로 키워 모든 프레임에 안전 여백을 확보했습니다.
  (좌우 최소 36px, 위 최소 17px, 아래 최소 19px)
- 결과적으로 파일 용량도 1.92MB → 1.20MB로 줄었습니다.

## 다시 만들려면

```bash
pip install pillow numpy scipy
python design-assets/turini-animation-v1/repack_to_v2.py
```

`public/assets/turini-atlas-v2.png` 와 `turini-atlas-v2.json` 이 새로 만들어집니다.
스크립트는 프레임마다 칸 안 여백을 출력하므로, 원화를 새로 받았을 때
잘림 여부를 숫자로 바로 확인할 수 있습니다.
